# Unit #3205 (Tower 2) Photo Assets

This directory hosts the authentic photography for **Waikiki Banyan Unit #3205-T2**.

## 🚀 GitHub & Vercel Reusable Hosting Configuration

The application is engineered with universal path resolution so these images load seamlessly whether hosted on:
- **Vercel** (serving at root `/`)
- **GitHub Pages** (serving at subpath repository `/repository-name/`)
- **Netlify / Cloud Run / Custom Domains**

The system automatically resolves `import.meta.env.BASE_URL` and safely URL-encodes special characters (spaces and `#` tags) so URLs never break.
